📲 Quiz als app op je telefoon zetten (mag, hoeft niet)

Doe dit nu, vóór je je aanmeldt. Daarna kan het niet meer.

iPhone (Safari): tik onderin op Deel (vierkantje met pijl omhoog) → Zet op beginscherm → Voeg toe.

Android (Chrome): tik rechtsboven op ⋮ → Toevoegen aan startscherm. Je krijgt een icoon dat de quiz in Chrome opent; "App installeren" biedt Android hier niet aan.

Sluit daarna dit venster en open de quiz via het nieuwe icoon. Meld je dáár aan.
